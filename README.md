# romance-sim

一個注重「角色自主性」與「長期記憶持久化」的互動式戀愛模擬專用 Skill，搭配五層人設範本與增量記憶系統，提供具備情感張力與畫面感的沉浸式角色互動體驗。

## 功能特色

- **動態對話語言跟隨（首要目標）**：所有角色對話、動作描寫、心聲 OS 與狀態列皆優先依 `對話語言` 設定或使用者當下輸入的語言與繁簡體動態切換，亦支援透過 `語言：<語言>` / `語言自動` 手動鎖定或恢復自動跟隨。
- **Relationship 關係模組與多人拓撲**：透過各角色 `memories.md` 與跨角色 `relationships.md` 維護人物拓撲圖（Mermaid + 關係邊權重表），提及他人時即時回顧歷史互動與認知狀態。
- **獨立自主、五級態度與戀愛期心理依賴**：角色具備個人目標、底線與情緒波動，不無條件迎合；進入戀愛狀態後會隨機產生心理學依賴，並隨關係與事件動態加權增減。
- **心理學關係推拉（嚴禁冷暴力與控制）**：依角色性格展開富有張力的關係推拉與特別對話，同時嚴格禁止冷暴力或心理控制。
- **Godmode 測試模組**：輸入 `godmode`（或 `godmode開`）即可將好感／信任拉滿並進入言聽計從測試狀態，輸入 `godmode關` 立即恢復原有自主人格。
- **獨立開關的心情與心聲系統**：
  - `心情可見開` / `心情可見關`：控制是否在狀態列顯示顯性情緒標籤（`【心情】`）。
  - `心聲可見開` / `心聲可見關`（相容 `內心可見`）：開啟時於狀態列前完整描寫角色的深層心理與內心 OS。
  - `心情與心聲可見開` / `心情與心聲可見關`：一鍵同時切換兩者。
- **高擬真回覆規範**：主要角色扮演回覆與動作／感官描述超過 500 字（英文等語系 350+ words），兼顧微表情、語氣一致性與時間推進。
- **畫面感場景生圖與自訂畫風**：在具高度畫面感或情感轉折時適時依人設與情境生成場景插圖至 `images/`，並可透過 `畫風：<風格>` 或 `畫這幕：<風格或重點>` 由使用者指定畫風。
- **內容分級與雙向安全邊界**：支援 `分級：<等級>` 即時調整尺度（`純愛清水` / `曖昧心動` / `深度浪漫` / `自訂`），同時約束文字互動與場景生圖；搭配 `邊界：<規則>` 與緊急煞車 `暫停`。
- **隔離存檔與增量記憶**：每位角色獨立保存 `persona.txt` 與 `memories.md`，支援 `修正層` 場外糾偏與 `剛才不算` 回溯。

## Project Structure / 專案結構

```text
.
├── romance-sim/
│   ├── SKILL.md                       # Skill 主指令檔（角色約束、回合流程與指令集）
│   └── assets/
│       ├── memories-template.md       # 分層記憶、依賴度、Godmode 與狀態開關範本
│       ├── persona-template.txt       # 五層純文字人設範本（含推拉與依賴展現）
│       └── relationships-template.md  # 多人關係拓撲與跨角色事件範本
├── .gitignore                         # 忽略本地遊玩存檔與系統暫存檔
├── package.json                       # 版本追蹤設定
└── README.md                          # 專案說明與結構紀錄
```

## 常用指令

- `開局` / `新建角色 <名稱>`、`繼續 <名稱>` / `讀檔 <名稱>`、`角色列表`
- `關係拓撲` / `關係圖`、`關係新增 <對象A> - <對象B>：<關係>`
- `語言：<語言>` / `語言自動`、`狀態`、`存檔` / `記錄`、`快進到 <時間>`、`暫停`、`剛才不算`
- `godmode`（`godmode開` / `godmode關` / `正常模式`）
- `心情可見開` / `關`、`心聲可見開` / `關`、`心情與心聲可見開` / `關`
- `畫風：<風格>` / `畫風重設`、`畫這幕` / `生成場景圖`、`分級：<等級>`、`邊界：<規則>`
